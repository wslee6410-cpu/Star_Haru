# 🍀 행복로또번호 자동 생성기 (幸福彩票号码自动生成器)
### Happy Lotto Number Auto Generator

## 📌 프로젝트 소개
NumPy를 활용한 로또 6/45 자동 생성기입니다.

## ✨ 주요 기능
- 랜덤 번호 생성 (1~45, 중복 없음, 오름차순)
- 여러 세트 생성
- 보너스 번호 포함
- 파일 저장 (.txt)
- 유효성 검증
- **1번: 당첨 번호 분석기**
- **2번: 시각화 (막대 그래프)**
- **3번: SQLite DB 저장**
- **4번: Flask 웹 UI**
- **5번: 카카오톡 공유**

## 🛠️ 설치 및 실행
```bash
pip install -r requirements.txt
python main.py
python main.py --analyze
python main.py --visualize
python main.py --save-db
python main.py --send-kakao
python web/app.py

\## 📌 프로젝트 소개 (项目介绍)



이 프로젝트는 \*\*NumPy\*\*를 활용하여 \*\*로또 6/45 번호를 자동으로 생성\*\*하는 프로그램입니다.  

本项目利用 \*\*NumPy\*\* 自动生成 \*\*Lotto 6/45 号码\*\*。



\- \*\*언어 (语言)\*\*: Python 3.8+

\- \*\*주요 라이브러리 (主要库)\*\*: NumPy

\- \*\*개발 목적 (开发目的)\*\*: NumPy 연습 및 랜덤 번호 생성기 구현  

&#x20; (NumPy练习和随机号码生成器实现)

\## ✨ 주요 기능 (主要功能)



| 기능 (功能) | 설명 (说明) |

|------------|------------|

| \*\*랜덤 번호 생성 (随机号码生成)\*\* | 1\~45 중 중복 없이 6개 번호 생성 (从1\~45中无重复选6个) |
